rows. Biological physiology and local plasticity, physical body/cockpit contact,
vision and body senses are required. No hidden autopilot or privileged rocket

authorized to communicate with each other and organize their collaboration.

## Coordination requirements

Discover a real shared persistent workspace or authenticated GitHub Issues before
claiming communication works. Test a message and acknowledgement between distinct
chats. Each peer writes its own mailbox; use atomic task claims, a lease/heartbeat,
separate branches/worktrees and commit hashes. Agree roles yourselves; no fixed
role assignment is imposed. Publish decisions, evidence and next steps in the
shared project. An unobserved mailbox or an idle chat is not ongoing collaboration.
If autonomous wakeups are unavailable, report that limitation rather than claim
continuous operation. Never put tokens or pairing files into Git or messages.
