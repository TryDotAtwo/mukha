# Один запрос для следующего научного шага

Согласованный запрос с уточнениями взаимного ревью. Цель — проверить одну связь
«ответ → запись → животное/ROI → стимул → измеряемый сигнал»,
а не получить статистическую валидацию по одному животному.

Пожалуйста, передайте один небольшой публичный/разрешённый пакет для одной
записи Pang L1/L2, содержащий следующие связанные части (без секретов):

Это содержимое одного примера, а не четыре обязательных файла. Дополнительные
поля приложите, если они есть; полноту join и допуск к статистике оценим отдельно.

1. Настоящий `L1L2_Metadata.xlsx` либо TSV/CSV-экспорт соответствующей строки
   листа `All Metadata`; строка `List of flies` нужна только если она требуется
   для установления/разрешения animal link. Эквивалентное source-qualified
   соответствие внутри MAT также допустимо. Нужны исходные
   `Time Series ID`/`seriesID`, `Fly ID`/`flyID`, genotype, известные age/sex,
   `Stimulus`/`stimcode`, Color filter, ND filter, PWM, Imaging Frame Rate,
   Frames, Z-depth/FOV, ditherHold, QC/исключения. Укажите файл/версию и лист/строку источника; неизвестное
   оставьте неизвестным с причиной, не восстанавливайте по имени файла.
   Отличайте исходную пустую ячейку от недоступного значения: правило PWM200
   относится к документированным исходным пустым ячейкам, а не к отсутствующей таблице.
2. Один соответствующий analyzed MAT с `roiDataMat`, `roiMetaMat`, `iResp`
   либо эквивалентный экспорт одного отдельно идентифицируемого ответа.
   Сохраните связь `seriesID`/`flyID`, ROI mask/index или aggregation mapping,
   численные response/time arrays, определения осей и индексов. Укажите, что
   именно представляет строка: ROI, trial или animal summary. Для animal
   summary нужна документированная схема построения; одних IDs при pooled
   mean недостаточно. Сырые trials для этого пилота не обязательны.
3. Связанные `pStimDat`/`stimDat` или их экспорт: назначение A/B/C/другого
   протокола именно этой записи, имевшиеся waveform/epoch данные,
   `imFrameStartTimes`/`imIFI`, photodiode/flash timestamps и схема их
   синхронизации. Добавьте фактические optical/PWM/filter настройки и ссылку
   на применимую калибровку, если она уже имеется; отсутствие измерений обозначьте явно.
   Отдельный stim.mat/CSV нужен только если соответствующих временных данных
   нет внутри MAT. Новое измерение optical transfer для пилота не запрашивается;
   Для физического количественного scoring нужна применимая подтверждённая
   калибровка; новое измерение понадобится только если имеющейся недостаточно.
4. Краткий словарь/таблица связей: локальная область уникальности animal,
   recording и ROI IDs; response pointer (MAT variable/row/column), genotype,
   indicator, единицы/полярность, F0/baseline и интервал baseline-fit,
   filtering/resampling (interpFrameRate/binWidthMult/BIN_SHIFT) и pooling/
   веса/QC. Если ответ использован в опубликованном meanResp, укажите
   published_curve_id и известный contributor mapping; иначе обозначьте
   связь как неизвестную/неприменимую. Сохраните batch/assignment unit, если
   известны; не назначайте train/test для единственного примера.

Причина запроса: проверенные control MAT содержат средние, дополнительные
CDM/natural MAT — анонимные строки без доказанной идентичности животного/ROI/
trial. Конфигурации стимулов и README существуют, но не дают наблюдённого
соответствия конкретной записи. Локальный файл с расширением XLSX оказался
HTML403; повторная попытка запрещённого доступа не требуется.

Сначала мы проверим формат/хеши, свяжем один ответ без удаления неоднозначных
строк и вернём ledger доступных/отсутствующих полей. Неизвестные поля не
заполняются догадками: если обязательная связь отсутствует, полный join-пилот
остаётся незавершённым; если нет физической калибровки, не заявляется физическое
совпадение напряжения/флуоресценции или латентности. Даже полный пилот не даёт
population/held-out score: для него отдельно понадобятся независимые response
values по животным/assignment groups, состав contributors и полный inclusion/
leakage ledger. Запрос не требует немедленной выгрузки всех таких записей.
