# Native deterministic release candidate

Source commit 1af3f44e70827e65904511b43bbc5653a63eb35d adds optional per-edge resource depletion/recovery and separate postsynaptic efficacy through fc_configure_release. Parameters must be supplied explicitly at a valid tick-zero state. Resource recovers exponentially each tick; a delayed presynaptic event releases U times available resource and depletes it by that amount. Conductance increment is original edge weight times efficacy times release. Reset restores resources to one. The existing default static path remains available. No long-term learning is implemented or enabled.

Foreground MoLab compiled this CUDA source for sm_120 and verified five two-neuron conditions against an independent closed-form resource/recovery and exponential conductance calculation. Source spikes and delays agree exactly. Maximum conductance error across the conditions is 1.942890293094024e-16, below the frozen 1e-10 tolerance. Zero control has no events or conductance.

Diagnostic parameters: weight 0.1, baseline U=0.5, recovery 1000 ms, interval 400 ms, synaptic decay 100 ms. Baseline PPR=0.6648399769821765. Halving U to 0.25 halves the first peak and raises PPR to 0.8324199884910886. Halving separate postsynaptic efficacy to 0.5 also halves the first peak but retains PPR=0.6648399769821765. These directions are properties of the chosen depletion model and diagnostic parameters, not quantitative reproduction of Yamada animals. The existing harness condition names contain scalar_half for historical compatibility; actual mechanisms now differ.
